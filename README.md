# 🏛️ Система Електронного Голосування - Верховна Рада України

Офіційна система електронного голосування, розроблена у стилі Верховної Ради України. Система дозволяє проводити реальні голосування з механізмом "ЗА/ПРОТИ/УТРИМАВСЯ", схожим на процедуру голосування в українському парламенті.

## 🇺🇦 Особливості Системи

- **Офіційний дизайн** - інтерфейс у стилі Верховної Ради України з національними символами та кольорами
- **Система сесій** - створення сесій з парольним захистом або відкритим доступом
- **Реальне голосування** - три варіанти голосування: 🟢 ЗА, 🔴 ПРОТИ, 🟡 УТРИМАВСЯ
- **Таймер** - налаштовуваний час для голосування
- **Логіка рішень** - рішення приймається, якщо "ЗА" > 50% депутатів або досягнуто необхідну кількість голосів
- **Детальна статистика** - перегляд того, хто і як проголосував
- **Мультимовність** - українська, російська та англійська мови
- **Адаптивний дизайн** - працює на настільних комп'ютерах та мобільних пристроях

## 🛠️ Технологічний Стек

- **Backend**: Node.js + Express
- **Real-time**: Socket.io
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Deployment**: Готово для розгортання на Render.com

## 🌐 Розгортання на GitHub та Render.com

### GitHub

1. Ініціалізуйте git репозиторій:
```bash
git init
git add .
git commit -m "Initial commit - Verkhovna Rada Voting System"
```

2. Створіть новий репозиторій на GitHub

3. Додайте remote і відправте код:
```bash
git remote add origin <ваш-github-repo-url>
git branch -M main
git push -u origin main
```

### Render.com

1. Перейдіть на [render.com](https://render.com) та зареєструйтеся

2. Натисніть "New +" і виберіть "Web Service"

3. Підключіть ваш GitHub репозиторій

4. Налаштуйте сервіс:
   - **Name**: rada-voting-system (або ваша назва)
   - **Region**: Виберіть найближчий регіон
   - **Branch**: main
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `node server.js`
   - **Instance Type**: Free (для тестування) або платний для продакшену

5. Натисніть "Create Web Service"

6. Render розгорне вашу систему і надасть URL:
   ```
   https://rada-voting-system.onrender.com
   ```

## 📖 Використання Системи

### Створення Сесії

1. Натисніть "Створити Сесію"
2. Введіть назву сесії та опціональний пароль
3. Введіть ваше прізвище депутата
4. Натисніть "Створити"
5. Поділіться кодом сесії з іншими депутатами

### Приєднання до Сесії

1. Натисніть "Приєднатися до Сесії"
2. Введіть 6-значний код сесії
3. Введіть пароль, якщо він є
4. Введіть ваше прізвище депутата
5. Натисніть "Приєднатися"

### Проведення Голосування (Голова)

1. У сесії натисніть "Нове голосування"
2. Введіть питання або назву законопроекту
3. Встановіть час для голосування (секунди)
4. Встановіть необхідну кількість голосів "ЗА" для прийняття
5. Натисніть "Почати голосування"

### Голосування

1. Коли починається голосування, натисніть одну з трьох кнопок:
   - 🟢 ЗА
   - 🔴 ПРОТИ  
   - 🟡 УТРИМАВСЯ
2. Зачекайте закінчення таймера або поки всі депутати проголосують
3. Перегляньте результати та рішення

### Перегляд Результатів

- Результати відображаються автоматично після завершення голосування
- Бачите кількість голосів за кожен варіант
- Рішення прийнято, якщо голосів "ЗА" > половини депутатів або досягнуто поріг
- Натисніть "Показати деталі голосування" для перегляду індивідуальних голосів

## ⚙️ Налаштування

### Зміна логіки рішень

Редагуйте функцію `calculateResults` у `server.js`:

```javascript
// Поточна логіка: прийнято, якщо ЗА > половини депутатів АБО ЗА >= необхідна кількість
if (forVotes > halfDeputies || forVotes >= voting.requiredVotes) {
    decision = 'accepted';
}
```

### Зміна таймера

Тривалість за замовчуванням - 60 секунд. Змініть у `public/rada-voting.html`:

```html
<input type="number" id="votingDuration" value="60" min="30" max="300" required>
```

### Додавання нових мов

Додайте переклади в об'єкт `translations` у `public/js/rada-app.js`.

## 🐛 Усунення Неправильностей

### Порт вже зайнятий

Якщо порт 3000 зайнятий, система автоматично використає змінну середовища PORT (встановлюється Render).

### Проблеми з підключенням Socket

Переконайтеся, що ваш брандмауер дозволяє WebSocket підключення. Render автоматично обробляє це.

### Сесію не знайдено

Перевірте код сесії - він чутливий до регістру та складається з 6 символів.
